Book Borrowing Tracker



About the Project



Book Borrowing Tracker is a beginner-friendly Python application for organizing book information and managing book records.



Features



\- Store book titles, authors, categories, and publication years.

\- Display saved book information.

\- Organize book records in one place.



Technologies Used



\- Python 3

\- Object-oriented programming

\- Classes, objects, and functions

How to Run



1\. Install Python 3.

2\. Download or clone this repository.

3\. Open a terminal in the project folder.
