Repair Cost Tracker



Overview

Repair Cost Tracker is a beginner-friendly Python project that helps users manage broken items and decide whether to repair or replace them. It records item details and estimated costs, compares both options, and calculates the total estimated repair cost of all recorded items.



Features

\- Add Broken Items: Record the item name, category, problem, repair cost, and replacement cost.

\- View Items: Display all recorded items and their details.

\- Search Items: Find items by name, ignoring uppercase and lowercase differences.

\- Compare Costs: Compare repair and replacement costs to determine the cheaper option and calculate the difference.

\- Record Decisions: Save a decision to repair, replace, or leave an item undecided.

\- Calculate Total Repair Cost: Calculate the combined estimated repair cost of all recorded items.

\- Delete Items: Remove items from the records.

\- Menu-Based Interface: Access features through a simple numbered menu.



Technologies Used

\- Python

\- Classes and objects

\- Lists

\- Functions

\- Loops and conditional statements

\- User input and console output



How Cost Comparison Works

The program compares the estimated repair cost with the replacement cost.



\- If repair costs less, it displays the estimated savings from repairing.

\- If replacement costs less, it displays the estimated difference.

\- If both costs are equal, it displays a message indicating that both options cost the same.



How to Run

1\. Make sure Python is installed on your computer.

2\. Download or clone the repository.

3\. Open a terminal in the project folder.

4\. Run the Python file:



&#x20;  python RepairCostTracker.py



&#x20;  Replace RepairCostTracker.py with your actual Python filename if it is different.



5\. Select an option from the menu and follow the prompts.



Data Storage

The program stores item records in a Python list while it is running. The records are not saved permanently, so they will be lost when the program closes.
